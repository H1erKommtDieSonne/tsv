# Асимптотика собственных функций в задаче 1

Задача на зачёт по курсу «Асимптотические методы в линейных задачах математической физики», семестр 7. [Условие задачи (PDF)](Zadacha15_26.pdf).

## Постановка

Рассматриваем спектральную задачу

$$
-\frac{d}{dx}\left((2-x)(x-1)\frac{d\psi}{dx}\right)=E\psi,
\qquad 1<x<2.
$$

Собственная функция $\psi$ должна оставаться ограниченной при $x\to 1+$ и $x\to 2-$. Коэффициент $a(x)=(2-x)(x-1)$ положителен внутри интервала и обращается в ноль на обоих концах. При больших $E$ решение осциллирует внутри интервала, а поведение у концов определяет, какие значения $E$ допустимы.

## План решения

1. Ввести малый параметр $h=E^{-1/2}$. Найти и визуализировать лагранжево многообразие. В координатах $(x,p)$ уравнение уровня имеет вид $a(x)p^2=1$, откуда получаются две ветви $p=\pm a(x)^{-1/2}$.
2. Построить асимптотику собственных функций через канонический оператор Маслова. Вывести осциллирующую формулу внутри интервала и исследовать, как она согласуется с ограниченными решениями у обоих концов.
3. Из согласования фаз получить условие квантования для $E$.
4. Получить представление асимптотики на всём интервале через специальные функции. Проверить, какие из указанных в условии функций подходят для внутренней области и окрестностей концов. Для внутренней области исходная модель тригонометрическая, для концов проверим бесселеву модель.

## Проверка по точному решению

Замена $t=2x-3$, $y(t)=\psi((t+3)/2)$ переводит интервал в $(-1,1)$ и даёт уравнение Лежандра

$$
-\frac{d}{dt}\left((1-t^2)\frac{dy}{dt}\right)=Ey.
$$

Точные собственные значения и собственные функции с точностью до множителя имеют вид

$$
E_n=n(n+1),\qquad \psi_n(x)=P_n(2x-3),\qquad n=0,1,2,\ldots
$$

При больших $n$ сравним значения $E$ из условия квантования с $E_n$. Для проверки формы собственных функций приведём точное и асимптотическое решения к общей нормировке и знаку, а затем сравним их графики внутри интервала и возле обоих концов.
